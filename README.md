# wolong
修复古老 dos 游戏「卧龙传」的水战 bug，此 bug 已经存在近 30 年，当委任战斗在水战的时候，无法发挥水战的隐藏数值，造成周瑜战不过夏侯惇的情况，此补丁专门修复水战 bug。

    【卧龙传 水战修复补丁】                                                   
                                                                              
    1. 将 KI.EXE.PATCH 重命名为 KI.EXE（去掉 .PATCH 后缀）                    
    2. 备份游戏目录下原 KI.EXE（改名为 KI.EXE.BAK 即可）                      
    3. 用新 KI.EXE 覆盖游戏目录中的同名文件                                   
    4. 验证:MD5 应为 725dd235348e870c97779e082c8ff1d5                         
                                                                              
    效果:委任(自动)战斗在海域地图(0xd1–0xd5)时,                               
    正确启用水战隐藏属性和水军兵种权重;                                       
    陆战、攻城逻辑与原版逐字节一致。
