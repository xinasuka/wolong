# 卧龙传 补丁（wolong）

修复 DOS 老游戏「卧龙传」的两个体验问题：**水战 bug** 与**援军弹窗泛滥**。两个补丁相互独立，可单用、也可合并用。本 repo 根目录的 `KI.EXE` 已打好双补丁，复制过去覆盖原版即可。

---

## 修复了什么

### ① 水战 bug（存在近 30 年）
- **现象**：委任（自动）战斗发生在海域时，不触发水战隐藏数值、也不启用各兵种的水战权重，导致水战名将反打不过旱鸭子——典型如「周瑜在水战打不过夏侯惇」。
- **根因**：原版判定战斗类型时，海域地图块未能正确识别为水战，战力计算走了陆战分支。
- **修复**：海域地图（块 0xd1–0xd5）正确识别为水战，启用对应隐藏属性与水军兵种权重。**陆战、攻城逻辑与原版逐字节一致**，不影响非水战场景。

### ② 援军弹窗泛滥
- **现象**：当「我方城池与敌方相邻、且城内无军团驻扎」时，每回合弹出「xx 前来请求援军」。游戏武将不多、城池很多，中后期到处都在弹，严重打断节奏。
- **修复**：关闭这条弹窗提示。**援军请求的逻辑本身保留**（城池仍会照常登记/接收援军），只是不再弹窗打扰，游戏机制不变。

## 安装

### 最简单的办法（直接用双补丁版）
1. **备份**游戏目录下的原版 `KI.EXE`（重命名为 `KI.EXE.BAK` 即可）。
2. 把本 repo 的 `KI.EXE`（已含双补丁）复制到游戏目录，覆盖同名文件。
3. 运行游戏验证。

命令示例（假设游戏目录是 `/path/to/game`）：
```bash
mv  /path/to/game/KI.EXE  /path/to/game/KI.EXE.BAK      # 备份原版
cp  KI.EXE  /path/to/game/KI.EXE                         # 覆盖为双补丁版
```

### 只要其中一个补丁
把对应文件复制成游戏目录里的 `KI.EXE`：
```bash
cp  KI.EXE.WATER     /path/to/game/KI.EXE     # 只修水战
cp  KI.EXE.NOAID     /path/to/game/KI.EXE     # 只关弹窗
cp  KI.EXE.WTRNOAID  /path/to/game/KI.EXE     # 两个都要(=双补丁)
cp  KI.EXE.BAK       /path/to/game/KI.EXE     # 还原原版
```

## 技术细节（可选阅读）

两个补丁各自只改动极少量字节，互不重叠，故可叠加；均可通过 `KI.EXE.BAK` 覆盖还原。

- **水战补丁**：在 `KI.EXE:0x5139`（战斗主函数入口内）插入一条远跳，转入文件尾部追加的检测代码（cave），按地图坐标判定是否为水战，从而正确触发水战隐藏属性与兵种权重。改动范围：header 长度/重定位项 + `0x5139` 处 5 字节跳转 + 尾部追加约 44 字节 cave。陆战/攻城路径未触碰。
- **援军弹窗补丁**：把 `KI.EXE:0x40ee` 处的 `call 0x8810`（显示「前来请求援军」消息，TALK.DAT 索引 38）替换为 3 个 `NOP`（`e8 1f 47` → `90 90 90`）。援军请求的登记逻辑（`[si+0x857]`）照常执行，仅去掉弹窗。全 EXE 中该消息索引仅此一处引用，不会误伤其它提示。
